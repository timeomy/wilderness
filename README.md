# 旷野公司 · 上线到 GitHub Pages

网页只是画面，**分数要有地方存**，所以还是需要一个后端。
用 Apps Script（和 NEXT 科技浪潮同一套），免费、不用伺服器。

一共两步，约 8 分钟。

---

## 第 1 步 · 后端（Apps Script）

1. 开 <https://sheets.new> 建一个新 Sheet，随便取名
2. 在 Sheet 里点 **扩展功能 → Apps Script**
3. 把 `Code.gs` 整个内容贴进去（覆盖原本的 `myFunction`）
4. **部署 → 新增部署作业**
   - 类型：**网页应用程式**
   - 执行身分：**我**
   - 存取权限：**任何人** ← 一定要选这个
5. 复制那串「网页应用程式网址」，长得像
   `https://script.google.com/macros/s/AKfycb..../exec`

### 立刻验证后端是好的

浏览器打开（把网址换成你的）：

```
你的网址?action=selftest&pin=4717
```

会看到 18 行 `PASS` 和 `"ok":true`。有 `FAIL` 就是贴错了，重贴一次。

---

## 第 2 步 · 前端（已经上线了）

网址已经开好，GitHub Pages 也已经打开：

**<https://timeomy.github.io/wilderness/>**

现在打开会看到「还没接上后端」，因为第 1 步的网址还没填进去。
填法（在这个资料夹里）：

1. 打开 `index.html`，把开头那一行：

   ```js
   const API="";
   ```

   改成第 1 步复制到的网址：

   ```js
   const API="https://script.google.com/macros/s/AKfycb..../exec";
   ```

2. 推上去：

   ```
   git add index.html
   git commit -m "接上 Apps Script"
   git push
   ```

3. 等 1 分钟，重新整理，画面就活了。

**只有那一行要改。**

## 不想上线，只想在家试玩

不用碰 Google，也不用 GitHub：

```
cd 到这个资料夹
node run_local.js
```

它会印出两个网址，电脑用 `localhost`，手机用 `192.168.x.x`（要同一个 WiFi）。
关掉视窗分数就没了，纯粹练习用。正式那天还是要走上面两步。

## 关主要知道的两条规则

- **第 6、7 天市场关着**（饥荒）。祭坛照开，所以那两天只有 📖 拿得到。
- **第 13 天起，签了就立刻拆一层楼**。第 13 天当天先把之前欠的 🪝 一次收完；
  第 13、14、15 天再签的，当场拆，钱留着但楼没了。最后三天不是白签的。

---

## 开场前 2 分钟检查

1. 电脑开网址 → 选「大屏幕」→ F11
2. 手机开同一个网址 → 选「市场」→ 选第 1 公司 → 按给 5 💰
3. 大屏幕上第 1 公司要有反应

有反应就成了。三位关主各自开一次自己的身份就可以。

---

## 改过 Code.gs 之后

一定要 **部署 → 管理部署作业 → 编辑（铅笔）→ 版本选「新版本」→ 部署**。
不然线上跑的还是旧版。

---

## 归零

主持人身份进去按「归零」，或直接开：

```
你的网址?action=reset&pin=4717
```

## 我测过什么

- `Code.gs` 的规则逻辑：**18 项全过**（在模拟的 Apps Script 环境跑过）
- `index.html` 接上真的 `Code.gs`，在浏览器里从头走过一遍：
  选身份 → 选公司 → 市场给钱 → 试探官掷骰 → 念 📖 → 大屏幕更新 → 主持人进出，
  **全程没有 JS 错误**
- 断线情况也测了：后端关掉时画面会出现提示，**面板不会被清掉**，后端回来自动恢复
- 密码：关主不用，改名和归零要

**没测到**：Google 那边实际部署后的行为。
所以第 1 步的 `selftest` 网址请一定要打开看一眼。
