# 旷野公司 · 十五天

现场玩的实时游戏。**3 到 5 位关主拿手机顾关站，学生分成六间公司走到关站前面互动，
大屏幕即时算分。**

十五天，每天一分钟，整场约十五分钟。

---

## 现场怎么摆

| 谁 | 拿什么 | 做什么 |
|---|---|---|
| 🖥️ 大屏幕 | 投影／电视／笔电 | 全场分数记在**这一台**，从头到尾不要关 |
| 💰 市场 | 关主手机 | 学生做完你出的事，按一下给 5 💰 |
| 🙌 祭坛 | 关主手机 | 要他们**双手举高、大声念出经文**，才按给 1 张 📖 |
| 🏗️ 工地 | 关主手机 | 够钱就帮他们盖高一层 |
| 🪝 试探官 | 关主手机 | 演坏人。「签这里，现在就给你 10 💰」 |
| 🎛️ 主持人 | **大屏幕那台就有**，或另一支手机 | 开始／暂停／下一天／撤销／归零 |

关主只有三位的话，市场和工地可以同一个人顾，祭坛和试探官分开顾比较有戏。

> ⚠️ **大屏幕那台不要切去「主持人」身份。** 一切换，那台就不再是主机，全场会停住。
> 主持人的按钮已经做在大屏幕上了：右上角 **🎛️ 主持** → 输密码 → 开始／暂停／下一天／撤销／归零。
> 想用手机遥控也可以，那就用**另一支**手机选「主持人」。

## 开场

1. 大屏幕那台开网址 → 选「🖥️ 大屏幕」→ F11 全萤幕
2. 萤幕上会出现一组**四个字母的房间号**，还有一条网址
3. 每位关主用手机开同一条网址，输入房间号，选自己的关站
4. 主持人按「▶︎ 开始」

学生不用手机。他们用脚走，用嘴讲，用手举。

## 三种跑法

### 一、直接上网玩（不用架伺服器）

**<https://timeomy.github.io/wilderness/>**

打开就能玩。大屏幕那台当主机，手机透过免费的公共中继跟它讲话。
你不用付钱，也不用架任何东西。

⚠️ **要知道的一件事**：中继是别人免费开放的公共服务，没有人保证它一直在。
测试的时候它被我们打断过线（已经修好，现在讲话讲得很省）。
**正式活动前一天，一定要照「开场」走一遍试试看。**

如果中途断线，大屏幕会跳「⚠️ 中继断线」，手机会跳「大屏幕安静了」并且**把按钮锁起来**，
不会让你按到旧分数上面去。分数没有丢，还在大屏幕那台里。

### 二、同一个 WiFi（目前**还没**接好，要的话跟我说）

`run_local.js` 和 `Code.gs` 是旧的 HTTP 后端，规则一样、自我测试 18 项全过，
但**现在的 `index.html` 已经改走中继，不再打 `/api`**，所以这条路目前接不上。

场地网路会挡 WebSocket、或者你要完全不靠外面的服务，跟我说一声，
我把 `index.html` 改成两种都支援：连得到 `/api` 就走本机，连不到才走中继。

### 三、Apps Script

同上 —— `Code.gs` 本身是好的（18 项全过），但前端要接回 HTTP 才用得上。

## 卡住了怎么办

每一页都出得来，不用关浏览器：

| 卡在哪 | 怎么出来 |
|---|---|
| 不小心选到「大屏幕」 | 右上角 **换**，或画面中间的 **← 我不是大屏幕，换身份** |
| 房间号打错，一直停在「等大屏幕」 | 画面最下面 **换房间** |
| 想整台重来（身份、房间、公司全清掉） | 画面最下面 **重选身份** |
| 电脑上随时想退出 | 按 **Esc** |

房间号会记在手机里，所以**打错一次会一直错下去** —— 用「换房间」改，不用清浏览器资料。

## 规则

每间公司开局：**10 💰、0 📖、⛺ 帐篷**。

**只有房子算分，钱一分都不算。**

| | 要多少 | 几分 |
|---|---|---|
| ⛺ 帐篷 | 开局 | 0 |
| 🛖 木屋 | 10 💰 | 10 |
| 🏠 石屋 | 20 💰 | 20 |
| 🏰 城堡 | 30 💰 | 30 |

**试探官**给 +10 💰，比市场做工（+5）快一倍。学生只有两条路：

- **📖 念出神的话** — 花 1 张 📖，**一定**赶得走，从来没有失手过
- **🎲 自己撑撑看** — 掷骰子，只有 1 和 2 撑得住。撑不住就签，签了欠 1 个 🪝

**日历**

- 第 **6、7** 天 🌵 饥荒，市场关着。祭坛照开 —— 没得赚的时候，试探最好听
- 第 **8** 天 🌾 市场重开
- 第 **12** 天 🕊️ 恩典，每间公司白白得到 1 张 📖。不是他们赚的
- 第 **13** 天 💸 还债日，**每欠 1 个 🪝，拆掉一层楼。钱买不回来**
- 第 13 天之后再签，**当场就拆**。最后三天不是白签的
- 第 **15** 天 🏁 结算

## 归零

主持人身份进去按「归零」。分数存在大屏幕那台的浏览器里，
换一台电脑当大屏幕，分数不会跟着走。

## 测过什么

- 规则逻辑 **18 项全过**（`Code.gs` 里的 `selfTest_`，在模拟环境跑过）
- 浏览器实测：大屏幕 + 关主手机分开两台，四个关站的动作都传得到，
  大屏幕即时更新，**没有 JS 错误**
- 断线情况实测：中继断掉时手机会挡住按钮、大屏幕会示警，接回来自动恢复
- **没测到**：真实场地的 WiFi 会不会挡掉中继。所以活动前一天请务必试一次
